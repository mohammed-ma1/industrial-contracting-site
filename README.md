# Industrial Contracting & Factory Website

A high-quality, modern single-page website template for contracting and industrial factory companies. Built with Angular standalone components.

## Features

- **Video Hero** - Full-screen video background with tagline and CTAs
- **Quick Quote Form** - Above-the-fold quote request form
- **About & Certifications** - Company story with certification badges
- **Services Grid** - Construction, Steel Fabrication, Manufacturing
- **Projects Portfolio** - Before/after project case studies with hover animations
- **Safety & Quality** - OSHA, ISO 9001, compliance standards
- **Contact Form** - Full contact and quote request form

## Design

- Industrial color palette: navy, steel gray, orange accents
- Scroll animations (fade-up on view)
- Responsive, mobile-first layout
- Smooth hover effects and transitions

## Development

```bash
npm install
npm start
```

Navigate to `http://localhost:4200/`

## Build

```bash
npm run build
```

Output in `dist/industrial-contracting-site/`

## Customization

- **Fonts**: Add Google Fonts (Bebas Neue, DM Sans) to `src/index.html` for production
- **Video**: Replace hero video URL in `hero.component.ts` with your project footage
- **Images**: Update project images in `projects.component.ts`
- **Content**: Edit component templates with your company information

## Tech Stack

- Angular 20 (standalone)
- SCSS
- Angular Animations
